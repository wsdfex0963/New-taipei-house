# 搜尋來源優先順序

針對每個建案，依下列優先順序搜尋公開資訊：

1. **591 新建案**（591.com.tw/newhouse）— 官方格局、坪數、公設比、銷售資訊
2. **591 實價登錄**（591.com.tw/actual-price）— 周邊實際成交行情
3. **樂居**（leju.com.tw）— 建案基本資料、實價登錄整合、建商背景
4. **住展房屋網**（myhousing.housefun.com.tw / 住展雜誌）— 建案評論、市場分析
5. **5168 實價登錄比價王**（5168.com.tw）— 周邊行情比價
6. **內政部不動產交易實價查詢服務網**（lvr.land.moi.gov.tw）— 官方實價登錄資料，缺乏其他來源時的權威備援
7. **一般 Google／新聞搜尋** — 建商背景、糾紛新聞、重大建設計畫、環境風險（淹水/土壤液化查詢：國土規劃地理資訊圖台 nlsc.gov.tw）

找不到的項目一律標記「未知待查詢」，不得編造數字或事實。
