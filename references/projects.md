# 目前追蹤建案清單

新增／刪除／修改建案只需編輯這份檔案，不需要動 SKILL.md 或腳本。
每個建案是一個 YAML 區塊，`build_xlsx.py` 若需要可直接解析此檔（目前流程是由執行時的
Claude 讀取本檔內容，整理成 `projects_data.json` 後再呼叫腳本）。

```yaml
- name: 民生新埔
  address: 新北市板橋區民生路三段186號附近（確切門牌待搜尋確認）
  metro: 捷運新埔站（步行約5分鐘，待確認）
  area: 板橋

- name: 敦南之森
  address: 待搜尋確認
  metro: 待搜尋確認
  area: 待確認（名稱疑似取自敦化南路意象，實際基地區域需搜尋確認）

- name: 新濠漾
  address: 待搜尋確認
  metro: 待搜尋確認
  area: 三重

- name: 新濠岳
  address: 新北市土城區中央路四段125巷、福田路交叉口
  metro: 待搜尋確認
  area: 土城

- name: 汐止星野之森
  address: 新北市汐止區茄福街一帶（全案分 A~G 區）
  metro: 待搜尋確認
  area: 汐止
  scope: A~G 全區都要看
  room_filter: 以1房為主，最多看到2房（3房以上不列入）

- name: 文德好境
  address: 台北市內湖區陽光街
  metro: 捷運文德站約650公尺
  area: 台北市內湖區（使用者確認就是內湖這案，非新北市）
  room_filter: 只看1房物件（2房以上不列入）

- name: 將捷MRT
  address: 新北市中和區景平路121號
  metro: 環狀線景平站捷運聯開共構宅（出站即到家）
  area: 中和
  note: 捷運聯開案，1~5F 為捷運站體、6~12F 住宅；僅部分樓層可售，其餘為捷運局分回
```

> 上述地址／捷運資訊除已確認者外，其餘均需在每次執行時重新搜尋確認，
> 找不到就標記「未知待查詢」，不可憑名稱猜測。
>
> `room_filter` 是**使用者的看屋篩選條件**（不是建案本身的產品限制）：填表時聚焦在符合
> 條件的房型（坪數、總價、格局），超出範圍的房型只需簡略帶過或註明「不在看屋範圍」。
>
> 「文德好境」雖位於台北市內湖區而非新北市，但使用者明確指定要納入比較，故保留於清單中。
